# Text fixtures — provenance

Every file here is committed so the test suite is deterministic offline. No
fixture was generated by this project unless the entry says so.

## `biditest.jsonl` — Unicode BidiTest

| | |
|---|---|
| Source | Unicode Standard Annex #9, `BidiTest.txt` |
| Upstream | https://www.unicode.org/Public/UCD/latest/ucd/BidiTest.txt |
| Licence | Unicode License v3 — https://www.unicode.org/license.txt |
| Format | one JSON object per test case: `types`, `mode`, `para`, `levels`, `reorder` |
| Size | 1.2 MB, unmodified upstream content |

Full conformance data for the UBA. A conforming implementation should pass
these; this project implements a **subset** (explicit levels and auto mode, LTR
and RTL runs) and the test suite asserts the subset it actually claims rather
than silently skipping the rest.

## `biditest-subset.jsonl`

Derived from `biditest.jsonl` by filtering to the cases `runtime/text` claims to
handle. Regenerable from the file above; committed so a failure is
reproducible without re-running the filter.

## `device-android13.jsonl` — real-device calibration

Text measurement traces captured from **Android 13, arm64-v8a, API 33**, on a
local Android emulator, via `Paint.measureText` and `Paint.FontMetrics`.

| | |
|---|---|
| Captured | during the runtime/text calibration work |
| Device | Android 13 arm64-v8a emulator, default (AOSP) system image |
| Fields | text, style, locale, device-measured width, ascent, descent, top, bottom |
| Licence | measured here; no third-party content |

This is the **only fixture in the repository that is a real measurement rather
than upstream data**, and it is the one the text module's error figures are
computed against. Roboto is not redistributable and is not included: the
measurements are the numbers, not the font.

## `cases.jsonl`

Hand-written measurement cases covering shapes the BidiTest set does not reach:
ellipsising at `START`/`MIDDLE`/`END`, combining marks, emoji, and mixed
script runs. Written for this project.

## `declared-fallbacks.rs.txt`

A copy of the declared-fallback table from `runtime/text`, kept as a test
fixture so a change to the fallback list is a visible diff rather than a silent
behaviour change.
