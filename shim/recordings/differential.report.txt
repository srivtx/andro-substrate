WHAT THIS DOES NOT SHOW
---------------------
The input was a fixed script, not an APK. The script is deterministic, so nothing here separates
the substrate from the app's own nondeterminism; on a real run the same diff would be
confounded by it. That control now exists and is committed: docs/divergence/0007-sync-differential.md
is the ADR, and shim/recordings/sync-differential.report.txt is its output. Read this
report as the mechanism demonstration it is. And a fact that did not move is not
thereby a fact about a real device: it is a fact about this program under two
substrates, and the third thing a study needs — what the program does on hardware — is
outside anything in these two files. See docs/decisions/0006-substrate-policy.md.
